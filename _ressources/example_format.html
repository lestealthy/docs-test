🔧 How to Blink an LED with Arduino – A Beginner’s Guide

Electronics can feel overwhelming at first, but one of the simplest and most rewarding projects is making an LED blink. This tiny circuit introduces you to the world of microcontrollers, hardware, and code.

---

📝 What You’ll Learn

- How to wire a basic LED circuit - Why resistors are essential - Writing and uploading Arduino code - Experimenting with timing and variations

---

⚙️ Required Components

1. Arduino Uno (or compatible board) 2. Breadboard 3. 1x LED (any color) 4. 220Ω Resistor 5. Jumper wires

💻 The Arduino Code

c
// Blink example
const int ledPin = 13; // Built-in LED on most Arduino boards
void setup() {
  pinMode(ledPin, OUTPUT); 
}
void loop() {
  digitalWrite(ledPin, HIGH); // turn LED on
  delay(500);                 // wait 0.5 second
  digitalWrite(ledPin, LOW);  // turn LED off
  delay(500);                 // wait 0.5 second
}

🔬 Experiment

  • Change the delay(500) to delay(100) and watch the LED blink faster.
  • Try using analogWrite() for dimming effects.
  • Add multiple LEDs on pins 8, 9, 10 for patterns.
