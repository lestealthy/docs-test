Cryptography Fundamentals

Introduction to Real-World Cryptography

As described in Real-World Cryptography, cryptography is about securing protocols against saboteurs. A protocol is a list of steps that one or more people must follow to achieve something, but we must account for adversaries looking to take advantage of us.

Symmetric Encryption

Symmetric encryption is one of the fundamental concepts of cryptography, used in the majority of cryptographic algorithms. It involves two functions:

Encryption Process 
// ENCRYPT function
encrypted_message = ENCRYPT(secret_key, message)

// DECRYPT function  
original_message = DECRYPT(secret_key, encrypted_message)

// Key characteristics:
// - Same secret key used for both operations
// - Output appears as random noise
// - Provides confidentiality

Kerckhoff's Principle

An essential principle in cryptography: Only the key is kept secret. The algorithm should be public and well-studied. This principle ensures that security relies on key secrecy rather than algorithm obscurity.

Security by Obscurity vs. Security by Design: A secure cryptographic algorithm should remain secure even when the attacker knows everything about the system except the secret key.

Hash Functions

Hash functions are fundamental algorithms used to create unique identifiers from bytestrings. They have several important properties:

Hash Function Properties 
// Deterministic: same input always produces same output
hash1 = SHA256("hello world")
hash2 = SHA256("hello world")
// hash1 == hash2

// One-way: easy to compute hash, hard to reverse
hash = SHA256(message)
// Computing message from hash is computationally infeasible

// Avalanche effect: small input changes cause large output changes
hash1 = SHA256("hello world")
hash2 = SHA256("hello world!")
// hash1 and hash2 are completely different

// Fixed output size: always produces same length output
// SHA256 always produces 256-bit (32-byte) output

Data Authentication

Data authentication ensures that messages haven't been modified in transit. This is achieved through Message Authentication Codes (MACs) or digital signatures.

Message Authentication Codes (MACs)

HMAC Implementation 
// HMAC-SHA256 example
uint8_t key[32];          // 256-bit key
uint8_t message[];        // Message to authenticate
uint8_t mac[32];          // Output MAC

// Generate MAC
hmac_sha256(key, sizeof(key), message, message_len, mac);

// Verify MAC
uint8_t received_mac[32];
if (memcmp(mac, received_mac, 32) == 0) {
    // Message is authentic
    printf("Message verified successfully\n");
} else {
    // Message has been tampered with
    printf("Message authentication failed\n");
}

Fault Injection Attacks

Fault injection is a powerful technique for bypassing security mechanisms by introducing controlled errors into the system. As described in The Hardware Hacking Handbook, these attacks can circumvent firmware signature verification, gain access to locked functionality, and recover cryptographic keys.

Types of Fault Injection

Side-Channel Power Analysis

Power analysis attacks exploit the correlation between power consumption and cryptographic operations to extract secret keys. This is a non-invasive attack that can be performed with relatively simple equipment.

Simple Power Analysis (SPA)

Power Trace Analysis 
// AES implementation vulnerable to SPA
void aes_encrypt(uint8_t *plaintext, uint8_t *key, uint8_t *ciphertext) {
    // Each round operation has distinct power signature
    // Key scheduling operations are visible
    // Conditional operations leak key bits
    
    // Round 1: Initial key addition
    add_round_key(plaintext, key);  // Power spike visible
    
    // Rounds 2-10: Main encryption rounds  
    for (int round = 1; round < 10; round++) {
        sub_bytes();     // S-box lookups create power variations
        shift_rows();    // Data movement patterns visible
        mix_columns();   // Galois field operations
        add_round_key(); // Key-dependent power consumption
    }
    
    // Final round (no mix_columns)
    sub_bytes();
    shift_rows(); 
    add_round_key();    // Final key operation
}

// Power analysis can reveal:
// - Key scheduling algorithm used
// - Number of rounds
// - Conditional operations
// - Data-dependent operations

Differential Power Analysis (DPA)

DPA is a statistical attack that uses multiple power traces to extract secret keys. It's more powerful than SPA and can break implementations that resist simple analysis.

DPA Attack Methodology 
// DPA attack on AES first round
// 1. Collect N power traces for different plaintexts
// 2. For each possible key byte guess:
//    a. Calculate hypothetical intermediate values
//    b. Partition traces based on bit value
//    c. Calculate difference of means
//    d. Look for significant difference

// Hypothetical intermediate value calculation
uint8_t intermediate_value(uint8_t plaintext_byte, uint8_t key_byte_guess) {
    return sbox[plaintext_byte ^ key_byte_guess];
}

// Partition traces based on bit value
// Group traces where bit 0 of intermediate value is 0 or 1
double calculate_dpa_correlation(uint8_t key_guess, int bit_position) {
    double sum_group_0 = 0, sum_group_1 = 0;
    int count_0 = 0, count_1 = 0;
    
    for (int i = 0; i < num_traces; i++) {
        uint8_t intermediate = intermediate_value(plaintexts[i], key_guess);
        
        if ((intermediate >> bit_position) & 1) {
            sum_group_1 += power_traces[i];
            count_1++;
        } else {
            sum_group_0 += power_traces[i];
            count_0++;
        }
    }
    
    // Return difference of means
    return (sum_group_1 / count_1) - (sum_group_0 / count_0);
}

// Correct key guess will show significant difference
// Incorrect guesses will show random differences

// 1. Secure Boot Implementation
typedef struct {
    uint32_t magic;           // Boot signature magic number
    uint32_t version;         // Bootloader version
    uint32_t hash[8];         // SHA-256 hash of firmware
    uint32_t signature[64];   // RSA signature
    uint32_t crc32;          // CRC32 checksum
} secure_boot_header_t;

bool verify_secure_boot(secure_boot_header_t *header) {
    // 1. Verify magic number
    if (header->magic != SECURE_BOOT_MAGIC) {
        return false;
    }
    
    // 2. Verify CRC32
    uint32_t calculated_crc = crc32((uint8_t*)header, 
                                   sizeof(*header) - sizeof(header->crc32));
    if (calculated_crc != header->crc32) {
        return false;
    }
    
    // 3. Verify RSA signature
    if (!rsa_verify(header->hash, header->signature, 
                   SECURE_BOOT_PUBLIC_KEY)) {
        return false;
    }
    
    // 4. Verify firmware hash
    uint32_t firmware_hash[8];
    sha256(firmware_data, firmware_size, (uint8_t*)firmware_hash);
    if (memcmp(firmware_hash, header->hash, 32) != 0) {
        return false;
    }
    
    return true;
}

// 2. Constant-Time Implementation
bool constant_time_compare(const uint8_t *a, const uint8_t *b, size_t len) {
    uint8_t result = 0;
    
    // XOR all byte differences
    for (size_t i = 0; i < len; i++) {
        result |= a[i] ^ b[i];
    }
    
    // Return true if all bytes are equal
    return result == 0;
}

void secure_delay() {

    uint32_t delay = secure_random_uint32() & 0xFF;

        __NOP();  // No operation
    }
}

Fault Injection Countermeasures

Glitch Detection and Mitigation 
// 1. Redundant Computation
bool verify_signature_redundant(uint8_t *message, uint8_t *signature) {
    bool result1, result2, result3;
    
    // Perform verification three times
    result1 = crypto_verify(message, signature);
    secure_delay();  // Break timing correlation
    result2 = crypto_verify(message, signature);
    secure_delay();
    result3 = crypto_verify(message, signature);
    
    // Majority vote
    int true_count = (result1 ? 1 : 0) + (result2 ? 1 : 0) + (result3 ? 1 : 0);
    return true_count >= 2;
}

// 2. Glitch Detection
typedef struct {
    volatile uint32_t *voltage_monitor;
    volatile uint32_t *clock_monitor;
    uint32_t expected_voltage_min;
    uint32_t expected_voltage_max;
    uint32_t expected_clock_freq;
} glitch_detector_t;

bool detect_glitch(glitch_detector_t *detector) {
    uint32_t current_voltage = *(detector->voltage_monitor);
    uint32_t current_clock = *(detector->clock_monitor);
    
    // Check voltage range
    if (current_voltage < detector->expected_voltage_min ||
        current_voltage > detector->expected_voltage_max) {
        return true;  // Voltage glitch detected
    }
    
    // Check clock frequency
    if (abs(current_clock - detector->expected_clock_freq) > 
        CLOCK_TOLERANCE) {
        return true;  // Clock glitch detected
    }
    
    return false;
}

// 3. Error Checking and Recovery
typedef enum {
    SECURITY_OK,
    SECURITY_GLITCH_DETECTED,
    SECURITY_VERIFICATION_FAILED,
    SECURITY_TAMPER_DETECTED
} security_status_t;

security_status_t secure_operation() {
    glitch_detector_t detector;
    init_glitch_detector(&detector);
    
    // Check for glitches before critical operations
    if (detect_glitch(&detector)) {
        return SECURITY_GLITCH_DETECTED;
    }
    
    // Perform redundant verification
    if (!verify_signature_redundant(message, signature)) {
        return SECURITY_VERIFICATION_FAILED;
    }
    
    // Check for glitches after critical operations
    if (detect_glitch(&detector)) {
        return SECURITY_GLITCH_DETECTED;
    }
    
    return SECURITY_OK;
}

static void masked_aes_encrypt(const uint8_t *plaintext, const uint8_t *key,
                              uint8_t *ciphertext) {
    uint8_t mask[16];
    uint8_t masked_plaintext[16];
    uint8_t masked_key[16];
    uint8_t masked_ciphertext[16];
    
    // Generate random mask
    sys_csrand_get(mask, sizeof(mask));
    
    // Apply mask to input
    for (int i = 0; i < 16; i++) {
        masked_plaintext[i] = plaintext[i] ^ mask[i];
        masked_key[i] = key[i] ^ mask[i];
    }
    
    // Perform AES with masked data
    struct cipher_ctx ctx;
    cipher_begin_session(crypto_dev, &ctx, CRYPTO_CIPHER_ALGO_AES,
                        CRYPTO_CIPHER_MODE_ECB, CRYPTO_CIPHER_OP_ENCRYPT);
    
    cipher_block_op(&ctx, masked_plaintext, masked_ciphertext);
    cipher_free_session(crypto_dev, &ctx);
    
    // Remove mask from output
    for (int i = 0; i < 16; i++) {
        ciphertext[i] = masked_ciphertext[i] ^ mask[i];
    }
}

#define JTAG_LOCK_PIN 5
#define JTAG_ENABLE_PIN 6

static bool jtag_locked = false;
static uint32_t jtag_unlock_attempts = 0;
static uint64_t jtag_lock_time = 0;

static void jtag_lock_interface(void) {
    const struct device *gpio_dev = device_get_binding("GPIO_0");
    
    // Disable JTAG interface
    gpio_pin_configure(gpio_dev, JTAG_LOCK_PIN, GPIO_OUTPUT_ACTIVE);
    gpio_pin_set(gpio_dev, JTAG_LOCK_PIN, 1);
    
    jtag_locked = true;
    jtag_lock_time = k_uptime_get();
}

static bool jtag_authenticate(const char *password) {
    if (jtag_unlock_attempts >= 3) {
        // Permanent lock after 3 failed attempts
        jtag_permanent_lock();
        return false;
    }
    
    // Verify password hash
    uint8_t password_hash[32];
    crypto_hash_sha256(password, strlen(password), password_hash);
    
    uint8_t stored_hash[32];
    secure_storage_read("jtag_auth", stored_hash, sizeof(stored_hash));
    
    if (memcmp(password_hash, stored_hash, 32) == 0) {
        jtag_unlock_interface();
        jtag_unlock_attempts = 0;
        return true;
    } else {
        jtag_unlock_attempts++;
        return false;
    }
}

static void jtag_unlock_interface(void) {
    const struct device *gpio_dev = device_get_binding("GPIO_0");
    
    gpio_pin_configure(gpio_dev, JTAG_ENABLE_PIN, GPIO_OUTPUT_ACTIVE);
    gpio_pin_set(gpio_dev, JTAG_ENABLE_PIN, 1);
    
    jtag_locked = false;
}

static void jtag_permanent_lock(void) {
    // Fuse JTAG interface permanently
    const struct device *gpio_dev = device_get_binding("GPIO_0");
    
    gpio_pin_configure(gpio_dev, JTAG_LOCK_PIN, GPIO_OUTPUT_ACTIVE);
    gpio_pin_set(gpio_dev, JTAG_LOCK_PIN, 1);
    
    // Set permanent lock flag in secure storage
    uint8_t lock_flag = 0xFF;
    secure_storage_write("jtag_permanent_lock", &lock_flag, 1);
}

typedef struct {

} kyber_keypair_t;

static int kyber_keygen(kyber_keypair_t *keypair) {
    uint8_t seed[32];
    sys_csrand_get(seed, sizeof(seed));
    
    // Generate polynomial coefficients
    uint16_t poly_a[KYBER_N];
    uint16_t poly_s[KYBER_N];
    uint16_t poly_e[KYBER_N];
    
    // Sample from centered binomial distribution
    for (int i = 0; i < KYBER_N; i++) {
        poly_s[i] = sample_centered_binomial();
        poly_e[i] = sample_centered_binomial();
    }
    
    // Compute public key: t = A*s + e
    uint16_t poly_t[KYBER_N];
    poly_multiply(poly_a, poly_s, poly_t);
    poly_add(poly_t, poly_e, poly_t);
    
    // Pack keys
    pack_poly(poly_s, keypair->private_key);
    pack_poly(poly_t, keypair->public_key);
    
    return 0;
}

static int kyber_encapsulate(const uint8_t *public_key, 
                            uint8_t *ciphertext, uint8_t *shared_secret) {
    uint8_t randomness[32];
    sys_csrand_get(randomness, sizeof(randomness));
    
    // Generate shared secret
    crypto_hash_sha256(randomness, sizeof(randomness), shared_secret);
    
    // Encapsulate using public key
    uint16_t poly_m[KYBER_N];
    uint16_t poly_r[KYBER_N];
    uint16_t poly_e1[KYBER_N];
    uint16_t poly_e2[KYBER_N];
    
    // Sample polynomials
    for (int i = 0; i < KYBER_N; i++) {
        poly_m[i] = sample_centered_binomial();
        poly_r[i] = sample_centered_binomial();
        poly_e1[i] = sample_centered_binomial();
        poly_e2[i] = sample_centered_binomial();
    }
    
    // Compute ciphertext
    uint16_t poly_u[KYBER_N];
    uint16_t poly_v[KYBER_N];
    
    poly_multiply(poly_a, poly_r, poly_u);
    poly_add(poly_u, poly_e1, poly_u);
    
    poly_multiply(poly_t, poly_r, poly_v);
    poly_add(poly_v, poly_e2, poly_v);
    poly_add(poly_v, poly_m, poly_v);
    
    // Pack ciphertext
    pack_poly(poly_u, ciphertext);
    pack_poly(poly_v, ciphertext + KYBER_POLY_SIZE);
    
    return 0;
}

// Groth16 ZK-SNARK proof system
typedef struct {
    uint8_t proof[192];  // 3 G1 points + 1 G2 point
    uint8_t public_inputs[32];
} groth16_proof_t;

static int groth16_prove(const uint8_t *witness, const uint8_t *public_inputs,
                        groth16_proof_t *proof) {
    // Generate random challenge
    uint8_t randomness[32];
    sys_csrand_get(randomness, sizeof(randomness));
    
    // Compute proof elements
    uint8_t a[64];  // G1 point
    uint8_t b[128]; // G2 point  
    uint8_t c[64];  // G1 point
    
    // Compute A = α + r*δ + Σ(ai*ui)
    point_add_g1(proving_key.alpha, randomness, a);
    for (int i = 0; i < witness_size; i++) {
        point_multiply_g1(proving_key.ui[i], witness[i], temp_point);
        point_add_g1(a, temp_point, a);
    }
    
    // Compute B = β + r*γ + Σ(ai*vi)
    point_add_g2(proving_key.beta, randomness, b);
    for (int i = 0; i < witness_size; i++) {
        point_multiply_g2(proving_key.vi[i], witness[i], temp_point_g2);
        point_add_g2(b, temp_point_g2, b);
    }
    
    // Compute C = (Σ(ai*wi) + h*tau)/γ
    point_multiply_g1(proving_key.gamma, randomness, c);
    for (int i = 0; i < witness_size; i++) {
        point_multiply_g1(proving_key.wi[i], witness[i], temp_point);
        point_add_g1(c, temp_point, c);
    }
    
    // Pack proof
    memcpy(proof->proof, a, 64);
    memcpy(proof->proof + 64, b, 128);
    memcpy(proof->proof + 192, c, 64);
    memcpy(proof->public_inputs, public_inputs, 32);
    
    return 0;
}

static bool groth16_verify(const groth16_proof_t *proof, 
                          const uint8_t *verification_key) {
    // Verify pairing equation: e(A,B) = e(α,β) * e(γ,δ) * e(C,γ)
    uint8_t left_pairing[64];
    uint8_t right_pairing[64];
    
    // Compute e(A,B)
    pairing_g1_g2(proof->proof, proof->proof + 64, left_pairing);
    
    // Compute e(α,β) * e(γ,δ) * e(C,γ)
    pairing_g1_g2(verification_key.alpha, verification_key.beta, temp_pairing);
    pairing_g1_g2(verification_key.gamma, verification_key.delta, temp_pairing2);
    pairing_g1_g2(proof->proof + 192, verification_key.gamma, temp_pairing3);
    
    point_multiply_g1(temp_pairing, temp_pairing2, right_pairing);
    point_multiply_g1(right_pairing, temp_pairing3, right_pairing);
    
    return memcmp(left_pairing, right_pairing, 64) == 0;
}

// True Random Number Generator
static int trng_get_bytes(uint8_t *output, size_t len) {
    if (!device_is_ready(entropy_dev)) {
        return -ENODEV;
    }
    
    int ret = entropy_get_entropy(entropy_dev, output, len);
    if (ret < 0) {
        return ret;
    }
    
    // Verify entropy quality
    if (!entropy_quality_check(output, len)) {
        return -EINVAL;
    }
    
    return 0;
}

// Entropy quality assessment
static bool entropy_quality_check(const uint8_t *data, size_t len) {
    // Check for patterns and bias
    uint32_t ones_count = 0;
    uint32_t runs_count = 0;
    bool last_bit = false;
    
    for (size_t i = 0; i < len * 8; i++) {
        bool current_bit = (data[i / 8] >> (i % 8)) & 1;
        
        if (current_bit) ones_count++;
        if (current_bit != last_bit) runs_count++;
        
        last_bit = current_bit;
    }
    
    // Check for sufficient randomness
    float ones_ratio = (float)ones_count / (len * 8);
    float runs_ratio = (float)runs_count / (len * 8);
    
    // Accept if within acceptable ranges
    return (ones_ratio > 0.4 && ones_ratio < 0.6) && 
           (runs_ratio > 0.4 && runs_ratio < 0.6);
}

// Cryptographically secure random number generation
static int secure_random_bytes(uint8_t *output, size_t len) {
    uint8_t *temp_buffer = k_malloc(len * 2);
    if (!temp_buffer) return -ENOMEM;
    
    // Collect entropy from multiple sources
    int ret = trng_get_bytes(temp_buffer, len);
    if (ret < 0) {
        k_free(temp_buffer);
        return ret;
    }
    
    // Mix with system entropy
    for (size_t i = 0; i < len; i++) {
        temp_buffer[i + len] = sys_rand32_get() & 0xFF;
    }
    
    // Hash to remove bias
    struct hash_ctx ctx;
    ret = hash_begin_session(crypto_dev, &ctx, CRYPTO_HASH_ALGO_SHA256);
    if (ret != 0) {
        k_free(temp_buffer);
        return ret;
    }
    
    ret = hash_update(&ctx, temp_buffer, len * 2);
    if (ret == 0) {
        ret = hash_final(&ctx, output);
    }
    
    hash_free_session(crypto_dev, &ctx);
    k_free(temp_buffer);
    
    return ret;
}

    setsockopt(sock, SOL_TLS, TLS_HOSTNAME, &hostname_verify, sizeof(hostname_verify));
    
    // Set cipher suites
    const char *ciphers[] = {
        "TLS_AES_256_GCM_SHA384",
        "TLS_CHACHA20_POLY1305_SHA256",
        "TLS_AES_128_GCM_SHA256"
    };
    setsockopt(sock, SOL_TLS, TLS_CIPHERSUITE_LIST, ciphers, sizeof(ciphers));
    
    // Connect to server
    struct sockaddr_in addr;
    addr.sin_family = AF_INET;
    addr.sin_port = htons(port);
    inet_pton(AF_INET, hostname, &addr.sin_addr);
    
    int ret = connect(sock, (struct sockaddr *)&addr, sizeof(addr));
    if (ret < 0) {
        close(sock);
        return -1;
    }
    
    return sock;
}

typedef struct {

static bool validate_certificate_chain(const x509_certificate_t *cert,
                                     const x509_certificate_t *ca_cert) {
    // Check certificate validity period
    uint64_t current_time = k_uptime_get() / 1000; // Convert to seconds
    if (current_time < cert->not_before || current_time > cert->not_after) {
        return false;
    }
    
    // Verify certificate signature
    uint8_t cert_hash[32];
    crypto_hash_sha256((uint8_t*)cert, sizeof(x509_certificate_t) - 256, cert_hash);
    
    // Verify signature using CA public key
    int ret = crypto_verify_rsa(ca_cert->public_key, cert->signature, 256,
                                cert_hash, 32);
    if (ret != 0) {
        return false;
    }
    
    // Check certificate revocation
    if (is_certificate_revoked(cert->serial_number)) {
        return false;
    }
    
    return true;
}

static bool is_certificate_revoked(const uint8_t *serial_number) {
    // Check against Certificate Revocation List (CRL)
    uint8_t crl_hash[32];
    secure_storage_read("crl_hash", crl_hash, sizeof(crl_hash));
    
    // Download and verify CRL
    uint8_t crl_data[4096];
    int crl_size = download_crl(crl_data, sizeof(crl_data));
    if (crl_size < 0) return false;
    
    // Verify CRL signature
    uint8_t crl_hash_calculated[32];
    crypto_hash_sha256(crl_data, crl_size, crl_hash_calculated);
    
    if (memcmp(crl_hash, crl_hash_calculated, 32) != 0) {
        return false; // CRL verification failed
    }
    
    // Check if serial number is in CRL
    return check_serial_in_crl(crl_data, crl_size, serial_number);
}

static int download_crl(uint8_t *crl_data, size_t max_size) {
    // Download CRL from certificate authority
    int sock = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
    if (sock < 0) return -1;
    
    struct sockaddr_in addr;
    addr.sin_family = AF_INET;
    addr.sin_port = htons(80);
    inet_pton(AF_INET, "crl.example.com", &addr.sin_addr);
    
    if (connect(sock, (struct sockaddr *)&addr, sizeof(addr)) < 0) {
        close(sock);
        return -1;
    }
    
    // Send HTTP request
    const char *request = "GET /crl/root.crl HTTP/1.1\r\n"
                         "Host: crl.example.com\r\n"
                         "Connection: close\r\n\r\n";
    
    send(sock, request, strlen(request), 0);
    
    // Read response
    int total_received = 0;
    uint8_t buffer[1024];
    int received;
    
    while ((received = recv(sock, buffer, sizeof(buffer), 0)) > 0) {
        if (total_received + received > max_size) {
            close(sock);
            return -1;
        }
        memcpy(crl_data + total_received, buffer, received);
        total_received += received;
    }
    
    close(sock);
    return total_received;
}

Network Intrusion Detection

typedef struct {
    uint32_t source_ip;
    uint32_t dest_ip;

    uint16_t dest_port;

#define MAX_CONNECTIONS 100
static connection_t connections[MAX_CONNECTIONS];
static uint32_t connection_count = 0;

static void analyze_packet(struct net_pkt *pkt) {
    struct net_ipv4_hdr *ipv4 = NET_IPV4_HDR(pkt);
    struct net_tcp_hdr *tcp = NET_TCP_HDR(pkt);
    
    // Extract connection information
    connection_t conn = {
        .source_ip = ipv4->src,
        .dest_ip = ipv4->dst,
        .source_port = tcp->src_port,
        .dest_port = tcp->dst_port,
        .protocol = ipv4->proto,
        .packet_count = 1,
        .last_seen = k_uptime_get()
    };
    
    // Check for existing connection
    connection_t *existing = find_connection(&conn);
    if (existing) {
        existing->packet_count++;
        existing->last_seen = conn.last_seen;
    } else {
        // Add new connection
        if (connection_count < MAX_CONNECTIONS) {
            connections[connection_count++] = conn;
        }
    }
    
    // Analyze for suspicious patterns
    if (detect_port_scan(&conn)) {
        security_alert("Port scan detected", &conn);
    }
    
    if (detect_dos_attack(&conn)) {
        security_alert("DoS attack detected", &conn);
    }
    
    if (detect_anomalous_traffic(&conn)) {
        security_alert("Anomalous traffic detected", &conn);
    }
}

static bool detect_port_scan(const connection_t *conn) {
    // Count connections from same source IP
    uint32_t connections_from_source = 0;
    for (uint32_t i = 0; i < connection_count; i++) {
        if (connections[i].source_ip == conn->source_ip) {
            connections_from_source++;
        }
    }
    
    // Alert if more than 10 connections from same IP
    return connections_from_source > 10;
}

static bool detect_dos_attack(const connection_t *conn) {
    // Check packet rate
    uint32_t packets_per_second = 0;
    uint64_t current_time = k_uptime_get();
    
    for (uint32_t i = 0; i < connection_count; i++) {
        if (connections[i].source_ip == conn->source_ip &&
            (current_time - connections[i].last_seen) < 1000) {
            packets_per_second++;
        }
    }
    
    // Alert if more than 100 packets per second
    return packets_per_second > 100;
}

static void security_alert(const char *message, const connection_t *conn) {
    printk("SECURITY ALERT: %s from %d.%d.%d.%d:%d\n",
           message,
           (conn->source_ip >> 24) & 0xFF,
           (conn->source_ip >> 16) & 0xFF,
           (conn->source_ip >> 8) & 0xFF,
           conn->source_ip & 0xFF,
           conn->source_port);
    
    // Block suspicious IP
    block_ip_address(conn->source_ip);
    
    // Send alert to security monitoring system
    send_security_alert(message, conn);
}

static int encrypted_write(const char *filename, const void *data, size_t len) {
    if (!storage.initialized) return -ENODEV;

    sys_csrand_get(storage.iv, IV_SIZE);
    
    // Encrypt data
    uint8_t encrypted_data[ENCRYPTED_STORAGE_SIZE];
    size_t encrypted_len;
    
    int ret = cipher_cbc_op(&storage.ctx, storage.iv, data, len,
                           encrypted_data, &encrypted_len);
    if (ret != 0) return ret;
    
    // Store IV + encrypted data
    uint8_t storage_data[IV_SIZE + encrypted_len];
    memcpy(storage_data, storage.iv, IV_SIZE);
    memcpy(storage_data + IV_SIZE, encrypted_data, encrypted_len);
    
    // Write to flash
    return flash_write(filename, storage_data, IV_SIZE + encrypted_len);
}

static int encrypted_read(const char *filename, void *data, size_t *len) {
    if (!storage.initialized) return -ENODEV;
    
    // Read from flash
    uint8_t storage_data[ENCRYPTED_STORAGE_SIZE];
    int ret = flash_read(filename, storage_data, sizeof(storage_data));
    if (ret < 0) return ret;
    
    // Extract IV and encrypted data
    memcpy(storage.iv, storage_data, IV_SIZE);
    size_t encrypted_len = ret - IV_SIZE;
    
    // Decrypt data
    ret = cipher_cbc_op(&storage.ctx, storage.iv, 
                       storage_data + IV_SIZE, encrypted_len,
                       data, len);

}

typedef struct {

#define MAX_HSM_KEYS 16
static hsm_key_t hsm_keys[MAX_HSM_KEYS];
static uint32_t hsm_key_count = 0;

static int hsm_generate_key(uint8_t key_type, uint8_t key_size, 
                           uint32_t *key_id, bool persistent) {
    if (hsm_key_count >= MAX_HSM_KEYS) return -ENOMEM;
    
    // Generate random key ID
    *key_id = sys_rand32_get();
    
    // Generate key material
    uint8_t key_material[64];
    int ret = secure_random_bytes(key_material, key_size);
    if (ret != 0) return ret;
    
    // Store key in HSM
    ret = hsm_store_key(*key_id, key_type, key_material, key_size);
    if (ret != 0) return ret;
    
    // Update key registry
    hsm_keys[hsm_key_count] = (hsm_key_t) {
        .key_id = *key_id,
        .key_type = key_type,
        .key_size = key_size,
        .persistent = persistent,
        .created_time = k_uptime_get(),
        .last_used = 0
    };
    
    hsm_key_count++;
    return 0;
}

static int hsm_sign_data(uint32_t key_id, const uint8_t *data, size_t len,
                        uint8_t *signature, size_t *signature_len) {
    // Find key
    hsm_key_t *key = find_hsm_key(key_id);
    if (!key) return -ENOENT;
    
    // Update last used time
    key->last_used = k_uptime_get();
    
    // Perform signing operation
    int ret = hsm_sign(key_id, data, len, signature, signature_len);
    if (ret != 0) return ret;
    
    // Verify signature
    ret = hsm_verify(key_id, data, len, signature, *signature_len);
    if (ret != 0) {
        // Clear signature on verification failure
        memset(signature, 0, *signature_len);
        return -EINVAL;
    }
    
    return 0;
}

static int hsm_encrypt_data(uint32_t key_id, const uint8_t *plaintext, size_t len,
                           uint8_t *ciphertext, size_t *ciphertext_len) {
    hsm_key_t *key = find_hsm_key(key_id);
    if (!key) return -ENOENT;
    
    key->last_used = k_uptime_get();
    
    // Generate random IV
    uint8_t iv[16];
    secure_random_bytes(iv, sizeof(iv));
    
    // Encrypt using HSM
    int ret = hsm_encrypt(key_id, plaintext, len, iv, ciphertext, ciphertext_len);
    if (ret != 0) return ret;
    
    // Prepend IV to ciphertext
    memmove(ciphertext + sizeof(iv), ciphertext, *ciphertext_len);
    memcpy(ciphertext, iv, sizeof(iv));
    *ciphertext_len += sizeof(iv);
    
    return 0;
}

static void hsm_key_cleanup(void) {
    // Remove expired keys
    uint64_t current_time = k_uptime_get();
    uint32_t write_index = 0;
    
    for (uint32_t i = 0; i < hsm_key_count; i++) {
        if (hsm_keys[i].persistent || 
            (current_time - hsm_keys[i].last_used) < (24 * 60 * 60 * 1000)) {
            // Keep key
            if (write_index != i) {
                hsm_keys[write_index] = hsm_keys[i];
            }
            write_index++;
        } else {
            // Remove key from HSM
            hsm_delete_key(hsm_keys[i].key_id);
        }
    }
    
    hsm_key_count = write_index;
}
