Circuit Analysis & Design

Understanding the fundamental principles of electronics is crucial for embedded systems development. This section covers the essential concepts you need to master.

Ohm's Law and Basic Circuit Analysis

Ohm's Law forms the foundation of all electronic circuit analysis. As stated in The Art of Electronics, this fundamental relationship governs all resistive circuits:

Fundamental Law 
V = I × R

Where:
V = Voltage (volts)
I = Current (amperes) 
R = Resistance (ohms)

Derived relationships:
I = V / R
R = V / I

Power relationship:
P = V × I = I² × R = V² / R
Key Insight from The Art of Electronics: "The art of electronics is explained by stressing the methods actually used by circuit designers – a combination of some basic laws, rules of thumb, and a nonmathematical treatment that encourages understanding why and how a circuit works."

For embedded systems, understanding voltage levels is critical:

  • Logic High (1): Typically 3.3V or 5V depending on the microcontroller
  • Logic Low (0): Near 0V (usually < 0.8V for TTL logic)
  • Input Threshold: The voltage level at which a digital input switches states
  • Noise Margins: The difference between guaranteed output and required input levels

For complex embedded systems, you'll need to understand:

Kirchhoff's Laws

Kirchhoff's Current Law (KCL): The sum of currents entering a node equals the sum of currents leaving the node.

C 
// Example: Current analysis for a microcontroller pin
// I_total = I_pullup + I_input + I_leakage
// Where:
// I_pullup = (Vcc - V_pin) / R_pullup
// I_input = V_pin / R_input (if input is high impedance)
// I_leakage = Leakage current (typically in microamps)

Kirchhoff's Voltage Law (KVL): The sum of voltage drops around any closed loop equals zero.

Capacitors

Capacitors are essential for power supply filtering, timing circuits, and signal coupling.

Capacitor Types and Applications

Active Components

Active components provide amplification, switching, and signal processing capabilities.

Transistors

Transistors are the fundamental building blocks of digital circuits and amplifiers.

BJT (Bipolar Junction Transistor) Characteristics
  • NPN Transistor: Current flows from collector to emitter when base is forward biased
  • PNP Transistor: Current flows from emitter to collector when base is forward biased
  • Current Gain (β): IC = β × IB (typically 100-300 for small signal transistors)
  • Saturation: Transistor fully on, VCE ≈ 0.2V
  • Cutoff: Transistor fully off, IC ≈ 0
MOSFET Characteristics
  • N-Channel MOSFET: Conducts when VGS > Vth (threshold voltage)
  • P-Channel MOSFET: Conducts when VGS < Vth
  • Gate-Source Voltage (VGS): Controls conduction
  • Drain-Source Resistance (RDS(on)): On-resistance when fully conducting
  • Gate Capacitance: Affects switching speed

Operational Amplifiers

Op-amps are essential for signal conditioning, amplification, and filtering in embedded systems. As described in The Art of Electronics, they are considered the "perfect component" for analog circuit design.

Ideal Op-Amp Characteristics (The Golden Rules)
The Art of Electronics - Golden Rules 
Golden Rule #1: The output attempts to do whatever is necessary
                to make the voltage difference between the inputs zero.

Golden Rule #2: The inputs draw no current.

Ideal Characteristics:
• Infinite Input Impedance (no current flows into input terminals)
• Zero Output Impedance (can drive any load)
• Infinite Open-Loop Gain: Vout = A × (V+ - V-)
• Infinite Bandwidth (works at any frequency)
• Zero Offset Voltage (Vout = 0 when V+ = V-)
• Infinite Common-Mode Rejection Ratio (CMRR)
• Zero Noise
From The Art of Electronics: "The operational amplifier is the most important building block in analog circuit design. It's the perfect component - it does exactly what you tell it to do, with infinite precision and speed."

Digital Logic Families

Understanding digital logic families is crucial for interfacing different components.

TTL (Transistor-Transistor Logic)

  • Supply Voltage: 5V ± 0.25V
  • Logic High: 2.4V - 5V
  • Logic Low: 0V - 0.8V
  • Input Current: ±1.6mA (high), -1.6mA (low)
  • Output Current: -0.4mA (high), 16mA (low)

CMOS (Complementary Metal-Oxide-Semiconductor)

  • Supply Voltage: 3.3V or 5V
  • Logic High: 0.7 × VCC - VCC
  • Logic Low: 0V - 0.3 × VCC
  • Input Current: ±1µA (very low)
  • Output Current: Limited by package and power dissipation

Power Electronics

Power management is critical for embedded systems, especially battery-powered devices.

Linear Regulators

Linear regulators provide clean, stable output voltage with simple design.

Linear Regulator Characteristics
  • Dropout Voltage: Minimum input-output voltage difference
  • Load Regulation: Output voltage change with load current
  • Line Regulation: Output voltage change with input voltage
  • Quiescent Current: Current consumed by regulator itself
  • Thermal Considerations: Power dissipation = (Vin - Vout) × Iout
Linear Regulator Selection
C 
// Power dissipation calculation
// P = (Vin - Vout) × Iout
// Example: 5V to 3.3V at 100mA
// P = (5V - 3.3V) × 100mA = 170mW

// Thermal resistance calculation
// θJA = (Tj - Ta) / P
// Where Tj = junction temperature, Ta = ambient temperature
// For TO-92 package: θJA ≈ 200°C/W
// Temperature rise = 170mW × 200°C/W = 34°C

Switching Regulators

Switching regulators offer higher efficiency but more complex design.

Buck Converter (Step-Down)
C 
// Buck converter duty cycle
// D = Vout / Vin
// Example: 12V to 3.3V
// D = 3.3V / 12V = 0.275 (27.5%)

// Inductor current ripple
// ΔIL = (Vin - Vout) × D / (L × f)
// Where f = switching frequency

// Output voltage ripple
// ΔVout = ΔIL × ESR / (8 × C × f)
// Where ESR = equivalent series resistance of output capacitor
Boost Converter (Step-Up)
C 
// Boost converter duty cycle
// D = 1 - (Vin / Vout)
// Example: 3.3V to 12V
// D = 1 - (3.3V / 12V) = 0.725 (72.5%)

// Peak inductor current
// IL(peak) = Iout / (1 - D) + ΔIL / 2
// Where ΔIL = inductor current ripple

Signal Integrity

Maintaining signal integrity is crucial for reliable embedded systems.

Transmission Line Effects

At high frequencies, PCB traces behave as transmission lines.

Characteristic Impedance
C 
// Microstrip characteristic impedance
// Z0 = (87 / √(εr + 1.41)) × ln(5.98h / (0.8w + t))
// Where:
// εr = relative permittivity of PCB material
// h = height of trace above ground plane
// w = width of trace
// t = thickness of trace

// Example for FR4 PCB (εr = 4.3):
// h = 0.1mm, w = 0.2mm, t = 0.035mm
// Z0 = (87 / √(4.3 + 1.41)) × ln(5.98 × 0.1 / (0.8 × 0.2 + 0.035))
// Z0 ≈ 50Ω
Reflection Coefficient
C 
// Reflection coefficient calculation
// Γ = (ZL - Z0) / (ZL + Z0)
// Where ZL = load impedance, Z0 = characteristic impedance

// For matched load (ZL = Z0): Γ = 0 (no reflection)
// For open circuit (ZL = ∞): Γ = 1 (total reflection)
// For short circuit (ZL = 0): Γ = -1 (total reflection with phase inversion)

EMI/EMC Considerations

Electromagnetic interference can cause system failures and regulatory compliance issues.

Common EMI Sources
  • Switching Power Supplies: High-frequency switching creates harmonics
  • Digital Circuits: Fast rise/fall times create high-frequency content
  • Clock Signals: Fundamental frequency and harmonics
  • Data Lines: High-speed data transmission
EMI Reduction Techniques
  • Ground Planes: Provide low-impedance return paths
  • Shielding: Enclose sensitive circuits in conductive enclosures
  • Filtering: Use ferrite beads and capacitors to filter high frequencies
  • Layout: Minimize loop areas and keep high-speed signals away from sensitive circuits

Thermal Management

Proper thermal design prevents component failure and ensures reliable operation.

Heat Transfer Mechanisms

  • Conduction: Heat transfer through solid materials
  • Convection: Heat transfer through fluid motion
  • Radiation: Heat transfer through electromagnetic waves

Thermal Resistance Network

C 
// Thermal resistance calculation
// θJA = θJC + θCA
// Where:
// θJA = junction-to-ambient thermal resistance
// θJC = junction-to-case thermal resistance
// θCA = case-to-ambient thermal resistance

// Junction temperature calculation
// Tj = Ta + (P × θJA)
// Where:
// Tj = junction temperature
// Ta = ambient temperature
// P = power dissipation

Cooling Solutions

  • Heat Sinks: Increase surface area for convection cooling
  • Thermal Pads: Improve thermal contact between components and heat sinks
  • Fans: Forced convection cooling for high-power applications
  • Heat Pipes: Efficient heat transport over distances

Component Selection Guidelines

Selecting the right components is crucial for system reliability and performance.

Environmental Considerations

  • Temperature Range: Commercial (0°C to 70°C), Industrial (-40°C to 85°C), Military (-55°C to 125°C)
  • Humidity: Consider moisture sensitivity and hermetic sealing
  • Vibration: Mechanical stress on components and connections
  • Radiation: Space applications require radiation-hardened components

Reliability Metrics

  • MTBF (Mean Time Between Failures): Average time between component failures
  • FIT (Failures in Time): Failures per billion device hours
  • Bathtub Curve: Failure rate vs. time (infant mortality, useful life, wearout)
  • Accelerated Testing: High-temperature testing to predict long-term reliability

Testing and Validation

Comprehensive testing ensures system reliability and performance.

Electrical Testing

  • Continuity Testing: Verify all connections are intact
  • Insulation Testing: Verify isolation between circuits
  • Power Supply Testing: Verify voltage levels and ripple
  • Signal Integrity Testing: Verify signal quality and timing

Environmental Testing

  • Temperature Cycling: Test operation over temperature range
  • Humidity Testing: Test operation in high humidity
  • Vibration Testing: Test mechanical robustness
  • EMC Testing: Test electromagnetic compatibility

ADC (Analog-to-Digital Converter) Configuration

ADC Setup Example 
// ADC Configuration for STM32
void ADC_Init(void) {
    // Enable ADC clock
    RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;
    
    // Configure ADC
    ADC1->CR2 |= ADC_CR2_ADON;           // Enable ADC
    ADC1->CR2 |= ADC_CR2_CONT;           // Continuous conversion
    ADC1->CR2 |= ADC_CR2_CAL;            // Start calibration
    
    // Wait for calibration complete
    while(ADC1->CR2 & ADC_CR2_CAL);
    
    // Start conversion
    ADC1->CR2 |= ADC_CR2_SWSTART;
}

uint16_t ADC_Read(void) {
    // Wait for conversion complete
    while(!(ADC1->SR & ADC_SR_EOC));
    
    // Return converted value
    return ADC1->DR;
}

Timer Configuration

Timer Setup for PWM 
// Timer PWM Configuration
void Timer_PWM_Init(void) {
    // Enable timer clock
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    
    // Configure timer for 1kHz PWM
    TIM2->PSC = 71;                     // Prescaler (72MHz/72 = 1MHz)
    TIM2->ARR = 999;                    // Auto-reload (1MHz/1000 = 1kHz)
    
    // Configure PWM mode
    TIM2->CCMR1 |= TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2;  // PWM mode 1
    TIM2->CCER |= TIM_CCER_CC1E;        // Enable output
    TIM2->CR1 |= TIM_CR1_CEN;           // Enable timer
    
    // Set duty cycle (50%)
    TIM2->CCR1 = 500;
}

Real-World Design Example: AC Power Control

From The Art of Electronics, here's a practical example of microcontroller-based AC power control:

AC Power Control with Zero-Crossing Detection 
// AC Power Control Implementation
#include 
#include 

volatile uint16_t power_level = 0;  // 0-100%
volatile uint8_t zero_cross_flag = 0;

// Zero-crossing interrupt
ISR(INT0_vect) {
    zero_cross_flag = 1;
}

// Timer interrupt for phase control
ISR(TIMER1_COMPA_vect) {
    if(zero_cross_flag && power_level > 0) {
        // Turn on triac after delay
        PORTB |= (1 << PB0);
        _delay_us(100);  // Triac gate pulse
        PORTB &= ~(1 << PB0);
        zero_cross_flag = 0;
    }
}

void set_power(uint16_t level) {
    if(level > 100) level = 100;
    power_level = level;
    
    // Calculate delay for phase control
    uint16_t delay = (100 - level) * 83;  // 83μs per 1%
    OCR1A = delay;
}

int main(void) {
    // Initialize I/O
    DDRB |= (1 << PB0);  // Triac control pin
    
    // Configure external interrupt for zero-crossing
    MCUCR |= (1 << ISC01);  // Falling edge
    GIMSK |= (1 << INT0);   // Enable INT0
    
    // Configure timer for phase control
    TCCR1B |= (1 << WGM12) | (1 << CS11);  // CTC mode, prescaler 8
    TIMSK |= (1 << OCIE1A);                // Enable timer interrupt
    
    sei();  // Enable global interrupts
    
    // Main loop
    while(1) {
        // Adjust power based on temperature, user input, etc.
        set_power(75);  // 75% power
        _delay_ms(100);
    }
}
