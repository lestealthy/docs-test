Navigation Test Page

This page is used to test the sidebar navigation. Check the browser console for debug messages.

Test Instructions:

  1. Open browser developer tools (F12)
  2. Go to the Console tab
  3. Click on any navigation link in the sidebar
  4. Check console messages to see if navigation is working

Expected Behavior:

  • Clicking subsection links should navigate to section files
  • Clicking topic links should navigate to section files with anchors
  • Console should show debug messages for each click
  • Active states should be applied to clicked links
