# Development Tools

Hardware tools, software tools, simulation, testing equipment.

## Hardware Tools

| Tool | Purpose | Price Range |
|------|---------|-------------|
| Oscilloscope | Signal analysis | $300-$10,000+ |
| Logic Analyzer | Digital capture | $100-$1,000 |
| Multimeter | Basic measurements | $50-$500 |
| Soldering Station | PCB assembly | $100-$500 |
| Power Supply | Bench power | $100-$500 |
| JTAG/SWD Debugger | In-circuit debug | $50-$500 |

## Software Tools

- **IDEs:** VS Code + PlatformIO, STM32CubeIDE, Keil MDK, IAR
- **Build Systems:** CMake, Make, Ninja
- **Version Control:** Git, GitHub, GitLab
- **CI/CD:** GitHub Actions, GitLab CI, Jenkins

## Simulation

- **SPICE:** LTspice, ngspice, KiCad
- **MATLAB/Simulink:** Model-based design
- **Proteus:** PCB + firmware simulation
- **QEMU:** Emulation for development
- **Renode:** Multi-node simulation
