# Learning Paths

Beginner, intermediate, advanced paths, specialization.

## Beginner Path

1. **Electronics Fundamentals**
   - Ohm's Law, Kirchhoff's Laws
   - Passive components (R, L, C)
   - Basic circuit analysis

2. **C Programming**
   - Pointers, structures, memory
   - Bit manipulation
   - Function pointers

3. **Microcontroller Basics**
   - GPIO, timers, interrupts
   - UART, SPI, I2C
   - ADC/DAC

## Intermediate Path

1. **Embedded C Advanced**
   - Memory management
   - ISR best practices
   - State machines

2. **RTOS Concepts**
   - Task scheduling
   - Synchronization (mutex, semaphore)
   - Message queues

3. **Communication Protocols**
   - CAN, Modbus
   - MQTT, HTTP
   - BLE, LoRa

## Advanced Path

1. **Embedded Linux**
   - Yocto Project
   - Device drivers
   - Kernel configuration

2. **Security**
   - Cryptography implementation
   - Secure boot
   - Side-channel analysis

3. **Robotics**
   - Kinematics
   - Sensor fusion
   - Path planning

## Specialization

- **Automotive:** ISO 26262, AUTOSAR, CAN FD
- **Medical:** IEC 62304, FDA guidelines
- **Aerospace:** DO-178C, ARP4754
- **Industrial:** IEC 61508, OPC UA
